# Code of Conduct

OpenBOM is a security project built by people who want software to be safer. We expect everyone who
takes part — in issues, pull requests, discussions and any other project space — to make that work
pleasant and productive for others.

## Expected behaviour

* Be respectful and assume good intent; disagree with ideas, not people.
* Give constructive, specific feedback and accept it gracefully.
* Be patient with newcomers and with people working in a second language.
* Credit others' work and research.
* Handle vulnerabilities responsibly: report them privately as described in [SECURITY.md](SECURITY.md),
  never as public issues, and never publish working exploits against users of OpenBOM.

## Unacceptable behaviour

* Harassment, insults, discriminatory jokes or language, and personal or political attacks.
* Publishing other people's private information without their explicit permission.
* Sharing malware samples, credentials or exploit code in project spaces outside an agreed, private
  disclosure channel.
* Sustained disruption of discussions, or any conduct that would be inappropriate in a professional setting.

## Enforcement

Maintainers may edit or remove contributions and temporarily or permanently restrict participation of
anyone whose behaviour violates this code. Report incidents privately through a GitHub security advisory
or by contacting the maintainers listed on the repository; reports are handled confidentially.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
